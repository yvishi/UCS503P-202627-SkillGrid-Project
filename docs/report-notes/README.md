# Report notes

These notes record what each task built, so the final project report and the weekly journals can be written from them. Every task appends one entry to the file of its stream, using the template below.

| File | Content |
|---|---|
| `00-baseline.md` | Work finished after the mid-term report (17 Sep 2026): the open skill catalog, and Wave 0 foundation tasks |
| `A-scoring.md` | Stream A: evidence-weighted skill scores |
| `B-teams.md` | Stream B: hackathons, teams and invitations |
| `C-discovery.md` | Stream C: teammate and team discovery |
| `D-peer-feedback.md` | Stream D: post-hackathon peer feedback |
| `E-tests-metrics.md` | Stream E: integration tests and the pilot metrics script |

## Template

```markdown
## <Task id>: <title>  (<date>, <author>)
- **What was built:** 2-4 sentences, user-visible behaviour first.
- **Design decisions:** each with the alternative rejected and why.
- **Files:** created/modified (paths).
- **Schema:** models/fields touched (or "none").
- **Tests:** test files + count; what they prove.
- **Numbers for the report:** lines added, tests added, any measured value.
- **Problems hit:** bug/obstacle -> fix (feeds the report's "Analysis" section).
- **Screenshots to take:** pages/states for the report figures.
- **UML impact:** which diagram changes (class / activity / sequence / use case).
```
