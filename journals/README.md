# Journals

One folder per team member, named `<roll-no>-<first-name>`,
e.g. `1024030xxx-yourname`. Each folder should contain:

- `index.md` — a running list linking to that member's
  weekly entries.
- One markdown file per entry, e.g.
  `w1-<short-title>.md`.

See the [course
template](https://github.com/tiet-ucs503/ucs503p-202627odd-template/tree/master/journals)
for a worked example.
